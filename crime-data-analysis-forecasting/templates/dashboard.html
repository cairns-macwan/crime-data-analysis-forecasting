About this dashboard
  • Trend chart: use this for seasonality and long-term patterns.
  • Types chart: shows which crime categories dominate a place or year.
  • Forecast chart: links your project to machine learning and future risk.
  • Hotspot map: connects spatial clustering with policing and safety decisions.

Together, these views demonstrate:

  • End-to-end flow: open data → MySQL → analytics → interactive visuals.
  • Ability to slice data by place, time and category in real time.
  • A foundation where more advanced ML models can plug in later.
Data Source: UK Police Open Data (2022–2024) · Tech stack: Python, Flask, SQLAlchemy, MySQL, Chart.js, Leaflet, Prophet · Focus: Trend analysis, category breakdown, spatial hotspots & forecasting
