# Crime Data Analysis & Forecasting System

An end-to-end data analytics and forecasting project built using UK Police open data.

The project combines data ingestion, cleaning, SQL database design, backend development, forecasting, and interactive visualisation to explore crime trends and geographic hotspots.

## Project Overview

This system was developed to analyse historical crime data and present the results through an interactive dashboard.

The project focuses on transforming large public datasets into clear and accessible insights for non-technical users.

## Key Features

- Data ingestion and preprocessing
- Crime trend analysis
- SQL-based filtering and aggregation
- Geographic hotspot mapping
- Interactive dashboard filters
- Forecasting of future crime trends
- REST API integration
- MySQL database storage

## Technologies Used

- Python
- pandas
- SQL
- MySQL
- Flask
- SQLAlchemy
- Chart.js
- Leaflet
- Plotly
- Git & GitHub

## Data Source

UK Police Open Data

The project uses publicly available crime datasets for analysis and educational purposes.
